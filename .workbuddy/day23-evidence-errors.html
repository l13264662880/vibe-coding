Day 23 证据 2｜三类错误提示统一 —— 全部是中文人话

接口：https://yuanjian-d5gdhcntg91022662.service.tcloudbase.com/api/tasks　·　2026-10-11　·　curl 实测

① 参数/校验错（400）

curl -X POST .../api/tasks -d '{"text":" "}'
{ "ok": false, "error": "任务内容不能为空" }

curl -X PATCH .../api/tasks?id=1 -d '{"position":3}'
{ "ok": false, "error": "没有可修改的字段（只支持 text / done / due / estimate）" }

② 资源不存在（404）

curl -X PATCH .../api/tasks?id=999 -d '{"estimate":5}'　·　curl -X DELETE .../api/tasks?id=999
{ "ok": false, "error": "任务不存在" }

③ 服务器内部错（500）—— 今天的主修改：裸报错改成人话

改前（裸报错，直接把内部细节甩给用户）：
  { "ok": false, "error": "网关写入错误 401: {\"message\":\"...\"}" }   ← e.message 原样返回
改后（中文一句话，细节只进服务端日志）：
  { "ok": false, "error": "服务器开小差了，请稍后再试" }

触发路径：db.js 抛出内部错误 → index.js 的 catch 拦截 → 用户收中文提示，完整报错留在 `tcb fn log` 的服务端日志里。

④ 方法不支持（405）+ 正常读回归（不受影响）

curl -X PUT .../api/tasks
{ "ok": false, "error": "只支持 GET、POST、PATCH 和 DELETE" }

curl ".../api/tasks?limit=2"
{ "ok": true, "data": [ { "id": 1, "text": "复习高数第三章", ... }, ... ] }　← 正常读 ✓
