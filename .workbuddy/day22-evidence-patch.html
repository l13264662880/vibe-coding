Day 22 证据 1｜PATCH 修改一条数据生效

接口：PATCH /api/tasks?id=19　·　公网地址：https://yuanjian-d5gdhcntg91022662.service.tcloudbase.com　·　2026-10-10

① 新建测试任务（POST）— 拿到 id=19，estimate = 30

curl -X POST .../api/tasks -d '{"text":"Day22演示任务","estimate":30}'
{ "ok": true, "data": { "id": 19, "text": "Day22演示任务", "position": 11, "done": false, "due": null, "estimate": 30 } }

改之前　GET /api/tasks 返回该条

{ "id": 19, "text": "Day22演示任务", "position": 11, "done": false, "due": null, "estimate": 30 }
↓ PATCH /api/tasks?id=19　body: {"estimate": 90}

改之后　PATCH 响应（Prefer: return=representation 返回更新后的行）

{ "ok": true, "data": { "id": 19, "text": "Day22演示任务", "position": 11, "done": false, "due": null, "estimate": 90 } }

③ 对照错误分支也验证过

PATCH 无可修改字段（{"position":5}） → 400 { "ok": false, "error": "没有可修改的字段（只支持 text / done / due / estimate）" }
PATCH 不存在的 id=999          → 404 { "ok": false, "error": "任务不存在" }
